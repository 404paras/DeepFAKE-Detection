🎭 About This Project

This web application demonstrates a state-of-the-art deepfake detection system developed as part of an M.Tech project. The system uses advanced deep learning techniques to analyze videos and determine their authenticity.

🔬 How It Works

The system processes video files using deep learning to detect manipulated content:

  1. Extracting frames uniformly from the video
  2. Preprocessing and analyzing each frame
  3. Detecting patterns and inconsistencies
  4. Classifying as REAL or FAKE with confidence scores

🎯 Use Cases

  • Social media content verification
  • News authenticity checking
  • Forensic video analysis
  • Research and education
  • Identity theft prevention
