\textbf{Font sizes:}
\begin{itemize}

\item Section headings: 14pt (see below)

\end{itemize}

More text here. The margins remain consistent throughout.

\chapter{Second Chapter}
This chapter also starts at the exact same position as the first chapter.

Body text with proper margins.

This is a regular page without a chapter heading. Notice that the text block position matches exactly with the chapter pages - the red frame shows the same 1-inch margins on all sides.

This is the key difference from the previous configuration:
\begin{enumerate}
\item All pages have 1-inch margins (top, bottom, left, right)
\item Chapter titles start at the same vertical position as normal text
\item No extra spacing is added to chapter pages
\item The text block is consistent across all pages
\end{enumerate}

This matches Microsoft Word's default behavior where margins are uniform throughout the document.
